## yt-dlp GUI Projects

- **kannagi0303/yt-dlp-gui** - Windows-only GUI with selectable quality, chapters, cookie support and configuration.
- **dsymbol/yt-dlp-gui** - Cross-platform PySide6 application with presets and SponsorBlock, metadata and subtitle toggles.
- **Bluegrams/Vividl** - Modern Windows app supporting parallel downloads, format selection and clipboard monitoring.
- **jeanslack/Videomass** - wxPython-based cross-platform front-end with many FFmpeg/yt-dlp options.
- **xcodian/youtube-dl-web** - Web interface for youtube-dl offering quality selection and subtitle download.
